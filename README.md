# Retflix: Movie Recommendation System using MovieLens 1M and TMDB Metadata

## Project Overview

Retflix is a movie recommendation system developed as the final project for CSC 575. The project explores and compares multiple recommendation paradigms using the MovieLens 1M dataset and enriched movie metadata obtained from TMDB.

The objective of the project is not only to build a working recommender application, but also to experimentally analyze how different recommendation models behave under the same dataset and evaluation framework.

The application is implemented using Django and Docker and allows users to:

* Register and login
* Rate movies
* Receive personalized movie recommendations
* Compare recommendations generated by multiple models
* View movie posters obtained through TMDB integration

### MovieLens 1M

The primary dataset used in this project is MovieLens 1M.

Dataset Statistics:

* 6,040 Users
* 3,883 Movies
* 1,000,209 Ratings

The dataset was converted into CSV format and split into:

* ratings_train.csv
* ratings_test.csv

for offline recommender evaluation.

## Recommendation Models

### 1. Content-Based Filtering

Uses movie metadata to recommend movies similar to those previously liked by the user.

Baseline Features:

* Genres

TMDB-Enriched Features:

* Genres
* Overview
* Keywords
* Cast
* Director
* Tagline

Techniques Used:

* TF-IDF Vectorization
* Cosine Similarity

---

### 2. Collaborative Filtering

Uses user-user similarity based on rating behavior.

Techniques Used:

* User-Item Matrix
* Cosine Similarity

---

### 3. Clustering-Based Recommendation

Groups similar movies into clusters and recommends movies from clusters preferred by the user.

Baseline Features:

* Genres
* Average Rating

TMDB-Enriched Features:

* Genres
* Overview
* Keywords
* Popularity
* Vote Average
* Average Rating

Techniques Used:

* TF-IDF
* KMeans Clustering

---

### 4. SVD Matrix Factorization

Learns latent user and movie factors from the rating matrix.

Techniques Used:

* Matrix Factorization
* Truncated SVD

## Evaluation Methodology

The project evaluates all recommendation models under identical conditions.

Evaluation Metrics:

* Precision@K
* Recall@K
* NDCG@K

Evaluation Parameters:

* Relevance Threshold = 4.0
* K Values = 5, 10, 20, 40, 80
* 200 Randomly Sampled Users

The same train-test split and user sample are used for all models to ensure fair comparison.

---

## Experimental Settings

### Baseline Experiment

Uses MovieLens 1M data only.

### TMDB-Enriched Experiment

Uses MovieLens 1M data together with TMDB metadata.

The purpose is to evaluate whether richer semantic movie information improves recommendation quality.

---

## Key Findings

* Collaborative Filtering and SVD achieved the strongest overall performance.
* Content-Based Filtering improved significantly after TMDB enrichment.
* Clustering improved substantially after TMDB enrichment.
* TMDB metadata had little effect on Collaborative Filtering and SVD because these models primarily rely on user-rating behavior.
* Rich metadata benefits content-driven recommendation approaches more than rating-driven approaches.
